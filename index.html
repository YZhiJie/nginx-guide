快速开始 ​

3 分钟跑通第一个站点（以 macOS 为例，其他系统见第 2 章）：

bash
# 1. 安装并启动
brew install nginx && brew services start nginx

# 2. 验证默认页
curl -I http://localhost:8080

# 3. 创建自己的站点
echo '<h1>Hello Nginx</h1>' > /tmp/hello.html
